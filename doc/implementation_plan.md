# 実装計画

## 目的

設計書を動作するシューティングゲームへ段階的に変換する。各段階で実行可能な状態を維持し、ゲームロジックとプラットフォーム依存処理を分離する。

## 実装順の原則

各フェーズで、実装後に必ず次を実行する。

1. `cargo fmt --check`
2. 対象機能の単体テスト
3. `cargo check`
4. 必要に応じて起動確認

画像、音声、GPU はゲームロジックから分離し、データ定義と実行時状態を混ぜない。大きな機能を一度に追加せず、各フェーズの完了条件を満たしてから次へ進む。
