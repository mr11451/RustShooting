## 主題
二次元縦スクロールシューティング

## 環境
ハードウェア：Windows PC
言語：Rust
ライブラリ：winit、wgpu、egui、rodio

## プログラム構成
# メインプログラム
・全体管理、イベント管理
# 描画ライブラリ
・スプライト機能、背景スクロール機能、60fps固定、480x640サイズとその倍（960x1280）、全体拡大機能付き
# メモリー管理
・基本的に固定サイズの領域を自己管理して使用する
・テーブル構成で自キャラ、自弾、敵キャラ、敵弾は同じ構造体を使用する
・自弾は成長特性テーブルで管理し、同時発射グループ数は４、６、８、１０、１２、グループ内弾数は１、２、３、４、５とする
・敵キャラは難易度設定によって１画面内の最大出現数を４、８、１２、１６の数で変更可能（数は後で調整）
・敵弾も難易度によって敵一体につき１、２、４、８の数で変更可能（数は後で調整）、よって最大弾数は８×１６＝１２８
・いずれもデータ領域の数なので、おのずと１画面に出現する最大数となる
# 入力デバイス管理
・キーボード操作、コントロールパッドに対応
# 音楽／効果音再生
・wav再生、合成機能

## 全体シーケンス
・タイトル画面→任意のキー押下またはコントローラのボタン押下でゲームのメイン画面に進む、何もしなければ３０秒でデモ画面に
・デモ画面→任意のキー押下またはコントローラのボタン押下でゲームのメイン画面に進む、何もしなければ３０秒で
・ステージ構成によるゲーム本体→ゲームオーバー検出で３０秒後にタイトル画面に、コンティニュー機能や回数はゲームオプションで設定可能
・エンディング

## 処理ループ
・キー入力
・キャラ移動
・背景移動
・効果音再生
・得点計算
・描画、キャラ、背景、得点など
・当たり判定（ダブルバッファの１フレーム遅延を考慮して描画後にする）

## キャラ詳細
# 自キャラ
・自キャラは入力デバイスの操作で移動、スペースキーまたはパッドのAボタンで自弾発射、自キャラはダメージ制で最初に１００HP（要調整）を持っている
・画面の各所にある成長アイテムを拾うことで打てる弾数と弾の威力が上がっていく（貫通弾もあり）
・自キャラが敵キャラや敵弾に当たると成長が初期状態に戻る、加えてダメージが各敵や敵弾の特性テーブルにある自キャラダメージに沿った値でHPが減る、その間は無敵状態３秒。HP０で残機が１減り、自キャラと自弾を消去したまま敵・敵弾・背景を10秒進行させ、その後ステージ先頭へ戻る。残機0ではゲームオーバーとする
・自キャラの成長は次のステージに引き継がれる、最大成長まで達した後の成長アイテム取得はHP回復としてストックされる（ダメージを受けた初期状態からストック数に応じて回復する）
# 敵キャラ
・敵キャラはスケジュールされたタイミングで規定位置から発生、設定された軌道で動き、発射パターンに従って固定角度または発射時の自キャラ方向へ敵弾を発射する。発射後に方向を変更するのはホーミング特性の弾だけとする
・起動処理を終えた敵キャラは背景の移動に沿って移動、そのとき画面から外れたら消去する
# 自弾
・自弾は各特性の動きで移動し敵キャラに当たると消え敵キャラのライフ値を設定された量だけ削る、ゼロになると破壊エフェクトとともに消え得点が加算される
・自弾種類、形状や特性はIDで管理、前方直線、固定角度、貫通、ホーミング（発射時にターゲットした敵に）など、ホーミングとターゲッティングは自動で行う四角枠を表示する
# 敵弾
・敵弾は各特性の動きで移動し自キャラに当たると消え自キャラのライフ値を設定された量だけ削る、ゼロになると破壊エフェクトとともに消えゲームオーバーになる
・敵弾種類、形状や特性はIDで管理し、固定直進、発射時自キャラ狙い、追尾を設定する。発射パターンには周期、放射数、32方向の回転方向を設定できる
# 当たり判定
・当たり判定は各キャラの特性テーブルにある矩形の領域を中心からの縦横サイズでエリアとして判定（全アイテム共通）
# キャラ管理方法
・スケジュール、特性データ、軌道データはそれぞれIDで通し番号で管理する

## ステージ構成
・ステージは全６ステージ、ステージごとに個性の異なる敵キャラが出現する、個性とは、軌道や弾の特性など
・各ステージの全長は３分（要調整）で背景のスクロール速度によって長さは異なる、単一画面の場合もあり、スクロール速度はスケジュールされる
・各ステージ序盤とクリア後には演出があり敵キャラは出てこない時間（３秒程度）となる、その間スケジュールは起動していない（フレームカウントしない）
・各ステージ最後に強敵（ボスキャラ）が出現し、それを破壊すればステージクリア
・自キャラのリボーン、コンテニュー時には各ステージ最初の演出から始まる
・成長アイテムは各ステージに４っつ程度スケジュールされている

## スケジュールデータ
・フレームカウント数、出現位置、敵種類、軌道データ、難易度レベル

##　軌道データ
・軌道種類（直線移動、円軌道、ベジェ曲線など）、移動先方向、回転半径（円軌道時）、単位速度、フレーム数

## 得点
・敵キャラIDに沿った得点表（特性テーブル）を参照して行う

## 画面構成
画面最下部にHPゲージ、得点表示、残自キャラ数、ストック状況を１行で表示する、余計なSCOREなどの文字は不要
デモ中のスコアランキングを10位まで表示、名前入力は３文字まで
